# Coach — personal training & nutrition tracker

A phone-first web app (installable on iPhone) for a 12-week cut to ~60 kg / ~10% body fat by 31 Dec 2026.

- **Train** — back-friendly Upper/Lower split (4×/week) + Grid classes. Pre-filled weights/reps, automatic progression, rest timer, swap any exercise from the gym library.
- **Food** — quick-add list of Singapore hawker, HeyBo, delivery and meal-prep foods; custom foods; daily calorie & macro targets.
- **Progress** — weight chart (7-day average vs target path), weekly calorie check-in, waist, Evolt scans, strength (estimated 1RM), backup/restore.
- **Plan** — the coaching playbook.

No build step: plain HTML/CSS/JS. Data is stored on-device (localStorage); export backups from Progress → Settings.

## Install on iPhone
1. Open the GitHub Pages URL in **Safari**.
2. Share → **Add to Home Screen**.
3. Always launch from the Home Screen icon.
